# 안전사고
## 사고관리
- 절차(현)
	1. 사고발생
	2. 초안 작성 후 팀장 결재 
	3. 안전환경팀 확인 후 보고서 완료
	4. 사고 재발 방지 대책
		- 전사 대상 사고 교육 ⇒ 생성 시 교육 master로 등록 
		- 강의식 or 회람식 선택
		- 세부 항목은 자동 설정 후 수정 가능하도록 설정 *논의 필요*
			- 교육 master 
				- 강의/집합: 기존 
				- 회람식: 열람 시 확인 여부 Y
		- 개선사항(기술적, 관리적, 교육적)
	5. 개선사항 개선 후 첨부파일 업로드 
		- 개선결과
			- 전산 상 등록 및 관리 
			- 각 항목별 책임부서(=작성부서)
			- 개선 예정일 컬럼 추가
				- 기술: 1개월
				- 교육/관리: 2주 
			- 위 일정 초과 시, 사유 작성 필수
			- 예정일 임박/초과 시 알람 
	6. 완료 
- 사고분류
	- 1등급: 인체상해(중상), 공정사고 ⇒ 안전환경팀 작성
	- 2등급: 인체상해(정상, First Aid), 공정, 비공정 ⇒ 안전환경팀/사고발생팀 작성
	- 3등급: 아차사고, 기타 ⇒ 사고발생팀 작성
- 양식 총 7개
	- 각 사고분류별 양식 6개
	- 공유용 양식 1개: 개인정보 X, 재발방지 및 교육용
		- 요약서
			- ref: 중대재해 사이렌 포스터
			- 전사 공유 필요
			- 회람식 교육을 통해 확인여부로 완료 처리 (모바일도 가능)
- 사고 등록
	- 사후 등록
	- 사고조사보고서 작성
	- 등급에 따라 사고발생부서/안전환경팀에서 작성
- 사고 현황표 (Time Table)
	- 사고발생부서 작성 
	- 사고 경위 및 후발 조치 작성 
- 각 항목별로 작성자 지정(안전환경팀, 발생부서) ⇒ 결재 완료 후에는 편집 불가
- 


## 사고발생 알림
- 모바일 앱 `응급` 버튼 
	- 버튼 클릭 시, 긴급 연락처 
	- 연락하여 장소, 시간, 소속, 내용 전달 후 해당 부서에서 사고 접수
	- 수신처: 안전환경팀, 도급업체, 소관부서, 관리감독자

## 재해현황
- 안전팀, 법무팀, 인사팀, 경영팀, 발생부서 등록자, 발생부서 팀장: 원본 확인 가능
- 그 외 전 사원: 공유용 요약서 열람 가능
- 통계
	- 근태정보 I/F 
	- 월별 요약 등 디테일 *추후 논의*

## 아차사고(Near miss)
- 주로 생산팀(계전팀) 작성
- 절차
	1. 양식 작성
	2. 결재
	3. 팀 내 교육
- 통계를 위한 기준정보 필요 *추후 전달*
- 가끔 위험성평가, 재발방지대책 작성하기도 함

## 산업재해조사표 
- 보완서 등록 
	- 인원 수는 다를 수도 있음
- 고위험사업장 판단 기준
- (온산) 보상보험 신청/승인에 필요
- 1개월 이내 

## 산업안전보건위원회
- 분기별
- 목표, 안건, 개선 진행
	- 개선 담당 부서(단일) 지정
	- 개선 예정일 지정 
- 자격현황의 관리감독자, 안전관리자, 공장장 등 호출 필요
- 현재 회의 후 작성 ⇒ 안건 지정 시부터 작성
- 절차
	1. 실무진들 안건 회의
	2. 안건 지정 
	3. 산업안전보건위원회 회의 
	4. 회의 결과 작성 
	5. 안건 별 개선 진행 후 개선 후 결과 작성
