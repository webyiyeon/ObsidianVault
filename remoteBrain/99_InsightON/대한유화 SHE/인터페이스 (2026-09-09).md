# 인터페이스 협의
## 인사/조직/근태
- MIS DB 에서 DB Link 방식으로 진행 - USER / SELECT 조건으로 전달 예정
	- **I/F 정의서** 전달 
- 근무조(A/B/C), 근태정보(출퇴근), 실 근로시간, 발령 사항 → 데이터 적합성 확인용
	- 근태정보
		- 급여 25일 기준으로 이전까지 근태 정보 마감
		- 일별로 결재 관리
		- 교육, 출장일 경우 필터링 필요 
		- O.T는 행 추가됨 
	- 발령 사항
		- 발령 코드 `신규입사`, `전보` 시 교육 필요
		- 사업장 이동이 많으므로 데이터 JOIN 시 주의 필요

## 자격/면허/법정 선임,지정
- VIEW 형태로 전달할 수 있도록 SPEC(**I/F 요청서**) 전달 

## 전자 결재 - 워크플로우
- **xml 파일**로 전달
	- 반려/승인 되면 SH 서비스의 Flag 값 변경 
	- *김부영 과장님과 디테일 논의 필요* 
- 협조전 신규 form 필요 시에는 신규 작업 필요

## 알림/문자 발송/협조전
- 개인번호 문자 발송 - SureM
- 단체번호 문자 발송 - 네이버
	- 단체번호를 변경하고 싶을 경우에는 번호 추가 및 KT 승인 필요 - 약 3주 이상 소요
- 메일 발송 - SMTP 서버 
	- 협조요청 공문 전달 

## 데이터 마이그레이션(일회성)
- File Server 
	- 직접 접근하기보단 dump 떠서 이동 (현재 FTP)

# 계정 정보
- 차후 SSO 도입 가능성도 있어서 해당 사항은 1~2월 중 재전달 및 논의
- 일단은 데이터 batch 사용해서, 기존 계정명과 pwd 가져오는 것으로 고려 중 *추후 논의*

#  유지보수 관련
- vpn은 서버 발급 이후 계정 발급 후 전달 예정
- 사용 PC/MAC 고정 인원 2명 요청

# 보안 관련
- 협력업체 포탈은 외부 노출이므로 별도 보안 정책 확인 필요
	- 모의 해킹/보안 적합성 평가 진행 여부
		- 별도 진행은 없음
		- 차후 보안 관련 사항 fetch 후 산출물에 포함시켜서 함께 제출
