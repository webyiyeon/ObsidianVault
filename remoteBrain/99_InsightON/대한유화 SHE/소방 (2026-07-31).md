	- 유종변경 등 특수한 경우가 아니면 변경 X
	- 지도 → 2D 이미지 작업 
		- 소방시설도 같이 사용할 수 있도록 ?
		- 큰 구획으로 나눈 다음 `전체 지도` > `확대된 지도` 
			- 확대는 1단계까지만 
			- 큰 구획은 6~10 points

	- 안전관리자 현황 
		- 지도에 안전관리자 배치 현황 보여주는 기능 (위험물, 보건, ... )
		- 클릭 시 연락처 및 안전관리자의 정보 
		- 경영팀과 소통 후 진행할 것

	- 소방/위험물 현황
		- 소방시설/건축물 현황
		- 수신기, 펌프: `전체 지도`
		- 소화전(상세) → 아이콘 클릭 시 정보: `확대된 지도`
		- 아이콘은 모두 동시에도 볼 수 있음(소방시설, 소화전 등)
		- 클릭 시 ==화재안전정보카드== (건물마다 모두 존재)
		- back data 전달 예정 (~10월 말까지)
