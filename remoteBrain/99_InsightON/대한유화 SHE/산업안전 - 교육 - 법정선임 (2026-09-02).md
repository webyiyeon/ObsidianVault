# 산업안전보건 교육

## 연간교육계획
- 정기 안전 보건 교육 
	- 집합 & 자체: 둘 다 해당하는 항목 추가
		- 위 경우, 추가 팝업으로 자체/집합 선택
		- 서로 다른 색상으로 보이도록 설정 

## 부서별 연간교육계획
- 각 부서의 연간교육계획은 '월' 단위가 기본
- 교육 담당자, 안전환경팀 설정 ⇒ 대리자도 설정 가능

## 교육 관리
- 교대 근무 조의 경우, 정기 안전 보건 교육을 분기 단위로 진행
	- 집합/자체(팀) 를 하루만에 하는 경우도 있음
		→ 관련해서는 사용자 사용 방법으로 정리 및 *추후 논의*
- 강의식 / 회람식 교육 관련 *추후 논의* 
- QR 코드 인증 시 교육 시작 시간, 종료 시간 노출 X
- 교육 이수 이력 관리 필요 
- 관리감독자 ⇒ 대리자 설정 필요? *추후 논의*

## 설문/평가 등록
- 교육 실시 전에 평가 등록
- 미참 시 미참 사유 작성 후 교육 완료

## 교안 관리
- 교육 과정 + 주제 
	- 교육 과정은 기준 정보 관리
	- ex) 정기 안전 보건 교육, 신입사원 안전 보건 교육, ....
- 교안 이력 관리 필요: 등록 일시, 등록 부서 등 컬럼 추가
- 교육 끝나면 자동으로 교육 과정 + 주제에 해당하는 교안 저장 
	- 자체에서 교안은 보통 없고 지침만 있어서 필수는 아님
- 타 부서의 교안도 조회 가능 


# 안전 지침/절차서 

## 안전 지침
- 사업장 별로 다름
- revision 관리 필요
- 양식 pdf 로 고정 (제약)
- LEVEL 구분 필요
	1. 사규(규정)
	2. 매뉴얼
	3. 지침 
		- 사규 검토 의뢰 후 결재 진행
		- 공장장까지 결재선 
		- 개정 완료 후 교육 필수
		- 변경관리에 포함 시킬지? ⇒ 변경 요소 관리에서는 필수 x *추후 논의*
	4. 기준(기준/표준/규격/수칙) → 본부장님 선에서 결재 완료 (타 팀 검토 x, 자체 개정 o)
		- 교육 필요? *추후 논의*
	5. 경영시스템 실행 기록 - 기타
