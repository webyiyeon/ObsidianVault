# 산업안전보건 교육
## 연간교육계획
- 종류: 법정교육 등 총 13건
	- 소방/위험물/가스 법정관리자, 관리감독자, 일반 사원, 채용, 특별, 협력업체, 안전관리자, PSM, 유해화학물질, 밀폐공간, 비상대응, 소방/안전 실무
- 교육 대상 선정
	- **나의 할일**: 개인이 로그인 시, 내가 들어야 할 교육 보여주기 
	- **팀의 할일**
- 연간교육계획에 작성되지 않는 교육 ⇒ 수시
	- 사고 발생 
	- 변경관리
	- 지침 발생 
	- 위의 경우, 각 화면의 교육 탭에서 작성 및 출력 
	- 데이터는 master에서 관리
- 유형
	- 자체 - 팀별 → 교육실시결과보고서 작성 필요 
	- 집합 - 사업장별



## 부서별 연간교육계획 
- 절차
	1. 연간교육계획 작성 후, 안전환경팀에서 각 부서에게 연간교육계획 작성 요청 협조전 전달 (12월 말까지 작성 필요)
		- 교육평가 필수 항목 체크(강의식 평가)
			- 교육 완료 후 3개월 내에 평가 완료 필수
		- 일정 변경 불가 항목 지정
	2. 각 부서에서 진행할 월별 교육 계획 작성 후 전달
	3. 안전환경팀에서 취합하여 오류 확인 
	4. 차후, 실제 교육 일정이나 계획 일정이 변경될 경우 안전환경팀에서 승인 필요
- 생산부 자체교육 (예: 공정안전교육)
	- 부서별 연간교육계획에 기반하여 월별 교육실시결과보고서 양식 자동 생성 및 **팀별 할일** 알람
- 정기 안전교육 분기별 **팀별 할일** 알람 



## 교육 관리
- 교육 당일 QR Code 생성하여 모바일로 서명
- 법정 교육, 정기, 집합 교육 등 필요한 경우는 교육 시작 시간 QR + 종료 시간 QR 하여 교육 수료 입증 
	- reference: 삼성 영상 시청각 교육 같은 경우 시간 소요해야만 수료 가능
- 특별안전보건교육
	- 부서 이동 시 등 들어야 하는 교육 **나의 할일** 알람 
		- 부서마다 들어야 하는 교육이 다름
		- 노무팀에서 인사정보 호출 필요
	- 채용 시부터 개인별로 이수한 교육 히스토리 관리 



## 인사사항관리
- 기존 유비스의 ==(교육)인적관리 + 자격면허현황==
	- 법적교육담당 모니터링 - 정기교육 대상자(수료 관리)
- 취급일지 작성 권한(대리자 포함)과 연관
- 최근교육일자, 차기교육일자를 자동 UPDATE 
- 유비스 데이터 UPDATE (X) SELECT ONLY
- 목적: 중복 선임 방지
	- 지정: 사내 기준 / 선임: 관공서 서류 제출 필요. 공문 발생.
	- 관리감독자 *지정*
	- 법정관리자(안전관리자, 보건관리자 등) *선임* 
- 유형별로 컬럼을 보고 싶은 것만 볼 수 있도록 조작 가능 



## 설문/평가 등록
- 주제별 문제 생성 
	- 새로운 교육 평가 시, 기존 문제 호출하여 사용 가능 
- 기존 유비스 데이터 이관 필요
- 문제 설명을 위한 그림 첨부 가능
- 문제 순서 랜덤 
- 기준 점수 미달 시, 재평가 2회 가능 
	- 총 3회 응시 후에도 미달 시, 재교육 절차 *추후 논의 필요*
- No 교육, No 교육평가
- 모바일에서도 교육평가 가능? *추후 논의 필요*
- 팀별 문제 수정은 팀 권한(원래는 관리감독자가 작성)
