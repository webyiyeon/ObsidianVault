 # 프로세스

> 수기계약 건에 대해서는 배제하고 진행 
> 다만, 수기계약을 뒷받침하기 위해 직접 입력 및 등록이 가능한 기능과 권한은 필요

 1. 견적 요청 작성
	 - 전자구매시스템(KOPS)
		 - 대한유화 전산팀 관리 시스템 
		 - 구매팀 전용, 안전팀은 접근 안됨
	 - 작성 시 유비스 '모니터링' 화면에 자동 추가 (I/F)
2. 사전안전평가 진행
	- '모니터링' 화면에서 안전평가 요청 시, '안전평가' 화면에 추가 
	- 적격수급업체 평가 
		- 자체 평가지 존재 
		- 평가 점수 목록에 자동 계산 및 반영 
			- 기준 점수 미 충족 시 못 넘어가게 하는 기능도 고려 *논의 필요*
		- 안전팀 평가 진행 후 PASS / FAIL 결과를 다시 KOPS로 전달(I/F)
		- 안전팀 평가 시, 자체 결재 진행 
3. 계약서 작성 
	- 구매팀에서 진행 
	- 산업안전보건관리비 작성 
4. 위험 정보 제공
	- 현재: 공지사항에 업로드하여 협력사가 직접 다운로드 및 확인하도록 진행 
	- 안전보건 협력사 포탈의 공지사항에 업로드하여, 협력사가 확인 시 확인 여부(YN) 체크
		- 울산공장의 경우 교육실시결과보고서도 제공받음 
5. 안전작업계획서 작성 
	- 개별 pdf 업로드 후 통합 pdf 출력, viewer 가능
