 # 프로세스
 1. 견적 요청 작성
	 - 전자구매시스템(KOPS)
		 - 대한유화 전산팀 관리 시스템 
		 - 구매팀 전용, 안전팀은 접근 안됨
	 - 작성 시 유비스 '모니터링' 화면에 자동 추가 (I/F)
2. 사전안전평가 진행
	- '모니터링' 화면에서 안전평가 요청 시, '안전평가' 화면에 추가 
	- 적격수급업체 평가 
		- 자체 평가지 존재 
		- 평가 점수 목록에 자동 계산 및 반영 
			- 기준 점수 미 충족 시 못 넘어가게 하는 기능도 고려 *논의 필요*
		- PASS / FAIL 결과를 다시 KOPS로 전달(I/F)
