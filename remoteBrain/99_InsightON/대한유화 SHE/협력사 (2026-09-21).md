# 사후 실적 평가 
- 안전관리 작업 계획서 평가 시 필요한 자료 제출 요청
	- 모자랐던 자료를 추가로 요청하는데, 플랫폼화가 잘 되면 이 과정은 작업 계획서 평가 단계에서 마무리 가능 
- 도급업체 평가표에 동기화 필요
	- 도급업체 평가표: 구매 부서에서 최종 작성 후 마무리
	- 준공 후 ==안전관리 실적 평가표== 작성
		- *양식 있으나 내부 논의 필요하여 추후 재전달 예정*
		- 유비스 연동 필요
- 준공 완료 절차
	1. 협력사에서 작업 부서로 준공 처리 확인 요청 
	2. 작업 부서에서 구매 부서로 준공 요청 
	3. 구매 부서에서 준공 검사서 작성하여 안전환경팀에게 협조전 발송
	4. **사후 실적 평가 진행**
		- 준공 검사서가 승인 완료되었다는 정보만 있으면 실적 평가 진행 가능
		- 협력사에게 자동으로 서류 제출 요청
		- 유화넷 I/F 필요 
	5. 구매 부서 정산 완료
