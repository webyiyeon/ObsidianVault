# 소방, 고압가스

## 소방
### 소방계획서
- 모든 파일은 pdf 상태로 열람
	- 한글(.hwp), 엑셀(.xlsx) ⇒ pdf 타입
- 이력 관리 X 수정(update)만 가능하면 됨 
	- 수정 권한: 안전환경팀 only
	- 열람 권한: 전직원
	- 열람 시, 다운로드 또는 인쇄도 불가능 
	- 열람 시, pdf viewer 


### 위험물 취급일지
- PIMS(계전팀 관리 system)
	- DB 접속 권한 신청 필요
	- 취급량 기재 시, 기본적으로 호출 후 key-in 
	- 취급량이 허가량을 넘었을 경우 빨간색 표시 및 저장 불가
#### 울산
- 기존 자격현황 관리 데이터 I/F
	- 안전 보건 전용 자격현황 관리 화면
		- 선임종류(위험물안전관리자 대리자, 자체소방대 등), 근무조, 선임대상(중복 선택 가능) 컬럼 추가
		- 이 때, 위치는 단위공장을 의미
		- 위에서 선임대상에 자체소방대 선정 시 교육 협조전 발송 ⇒ pdf 파일로 다운로드 가능 
- 취급일지 양식 변경 
	- 위험물 제조소 등 현황(메인) ⇒ 취급일지 작성 버튼 활성화
