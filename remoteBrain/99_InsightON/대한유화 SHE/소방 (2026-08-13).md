# 소방, 고압가스

## 소방
### 소방계획서
- 모든 파일은 pdf 상태로 열람
	- 한글(.hwp), 엑셀(.xlsx) ⇒ pdf 타입
- 이력 관리 X 수정(update)만 가능하면 됨 
	- 수정 권한: 안전환경팀 only
	- 열람 권한: 전직원
	- 열람 시, 다운로드 또는 인쇄도 불가능 
	- 열람 시, pdf viewer 


### 위험물 취급일지
- PIMS(계전팀 관리 system)
	- DB 접속 권한 신청 필요

#### 울산
- 기존 자격현황 관리 데이터 I/F
	- 경로: 유비스 > 인사/급여관리 > 인사사항관리 > 자격면허현황
	- 안전 보건 전용 자격현황 관리 화면
		- 선임종류(위험물안전관리자 대리자, 자체소방대 등), 근무조, 선임대상(중복 선택 가능) 컬럼 추가
		- 이 때, 위치는 단위공장을 의미
		- 위에서 선임대상에 자체소방대 선정 시 교육 협조전 발송 ⇒ pdf 파일로 다운로드 가능 
	- 선/해임 이력 조회 
- 취급일지 양식 변경 
	- 위험물 제조소 등 현황(메인) ⇒ 취급일지 작성 버튼 활성화
	- 기존 월별 양식은 그대로
		- `점검하기` 버튼 클릭 시 체크리스트/취급현황 팝업
			- 체크리스트: default는 모두 양호 선택된 상태 → 아닌 경우만 바꿀 수 있도록
			- 취급현황: PIMS 데이터 호출. 호출 데이터(재고량)가 기준(허가량)을 넘었을 경우 빨간색 표시 및 저장 불가
	- 재검토하기: 이미 검토 및 결재까지 모두 완료된 취급일지 양식을 대상으로 근태 데이터와 비교 검토
	- 검토하기
		- 근태 데이터와 비교하는데, 아직 근태가 미입력된 경우 파란색으로 표시
		- 근태와 안 맞는 경우 빨간색
		- 검토가 모두 완료된 취급일지는 목록에서 파란색 표시
	- 검토 완료된 취급일지는 내부 결재 
		- 승인 날짜는 미표시
- 취급일지 작성 담당자 현황 (통계) ⇒ 일지 미작성자 대상으로 메일 발송 가능 *추후 논의*

### 코칭 프로그램 (안전보건 코칭 시스템)

	2. 담당부서 조치 후, 조치 사항 사진 및 설명 업로드 
- 현재 개별 등록해야 하는 상황 ⇒ 일괄등록 기능하도록 
	- Excel Form 업로드 
	- UI 업로드
	- 이미지 업로드 중요함
